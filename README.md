# XR Motion / Data Explorer

Unity prototype for interactive playback and visualization of
time-series spatial datasets.

## Status

🚧 Work in progress.

The project is currently in the desktop development phase.
XR functionality will be added after the desktop MVP is complete.

## Goals

- Load spatial time-series data from CSV.
- Reproduce recorded movement in 3D.
- Visualize object trajectories.
- Inspect individual tracked objects.
- Explore the same dataset interactively in XR.

## Tech

- Unity 6.3
- C#
- OpenXR
- XR Interaction Toolkit
